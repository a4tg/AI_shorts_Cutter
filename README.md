# Final Project Video Cutter

Десктопная и CLI-утилита для автоматической генерации коротких вертикальных видео.

Сейчас проект ориентирован на такой сценарий работы:

1. Берётся одно длинное исходное видео.
2. Находятся подходящие фрагменты по речи или по музыкальному ритму.
3. Каждый фрагмент переводится в вертикальный формат.
4. Вертикальный кадр собирается из:
   размытой копии того же видео на фоне и
   исходного горизонтального видео как увеличенного слоя переднего плана.
5. Добавляются субтитры, необязательная подложка под субтитры, стикеры и дополнительный звук.
6. Экспортируется заданное количество клипов.

## Текущее состояние

Что уже реализовано:

* Рабочий пайплайн обработки с CLI-точкой входа.
* Простой десктопный GUI на `tkinter`.
* Вертикальная композиция на основе размытого фона и увеличенного переднего плана.
* Режим по речи и режим по битам.
* Отрисовка субтитров с необязательной полупрозрачной подложкой.
* `faster-whisper` как основной ASR-бэкенд с упором на GPU.
* Диагностика окружения для GPU/CPU, FFmpeg, NVENC и CUDA.
* Базовые локальные тесты для нормализации запросов и логики редактора кадров.

Что пока не реализовано:

* Нет продвинутого трекинга объекта или автокадрирования по лицу.
* Нет готового релизного пакета в репозитории.

## Требования

Минимум:

* Python `3.11+`
* FFmpeg должен быть доступен в `PATH`

Рекомендуется для полного пайплайна:

* NVIDIA GPU с поддержкой NVENC
* Сборка PyTorch с поддержкой CUDA
* `faster-whisper`
* `openai-whisper`
* `moviepy`
* `ffmpeg-python`
* `opencv-python`
* `librosa`

Установка зависимостей:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Если нужна работа на GPU, сначала установите совместимую с CUDA сборку PyTorch.

Можно переопределить модель ASR по умолчанию через переменную окружения:

```powershell
$env:FINAL_PROJECT_ASR_MODEL="large-v3"
python -m final_project.gui
```

## Проверка FFmpeg

На Windows:

```powershell
ffmpeg -encoders | findstr nvenc
```

На Linux/macOS:

```bash
ffmpeg -encoders | grep nvenc
```

Если `h264_nvenc` не отображается, значит FFmpeg либо не установлен, либо собран без NVENC.

## Использование

### GUI

Запуск:

```bash
python -m final_project.gui
```

В GUI можно выбрать:

* входное видео
* папку вывода
* количество клипов
* режим: `speech` или `beat`
* включение/выключение субтитров
* включение/выключение фона под субтитрами

При запуске приложение также проверяет:

* доступен ли CUDA PyTorch
* видна ли NVIDIA GPU
* установлен ли FFmpeg
* поддерживает ли FFmpeg `h264_nvenc`

После этого приложение работает:

* на GPU, если доступны и CUDA, и NVENC
* на CPU, если ускорение на GPU недоступно

Если обнаружена совместимая NVIDIA GPU, но поддержка CUDA/NVENC отсутствует, приложение покажет предупреждение с рекомендациями по установке.

### CLI

Базовый пример:

```bash
python -m final_project.main --input path/to/video.mp4 --output clips --count 5
```

Основные доступные опции:

* `--mode {speech,beat}`
* `--count N`
* `--coords x1 y1 x2 y2`
* `--blur-radius R`
* `--sticker PATH`
* `--sticker-size WIDTH HEIGHT`
* `--sticker-position POSITION`
* `--sound PATH`
* `--subtitles` / `--no-subtitles`
* `--subtitle-background` / `--no-subtitle-background`
* `--subtitle-fontsize N`

## Поведение вертикального видео

Преобразование в вертикальный формат по умолчанию работает так:

* слой фона: тот же исходный клип, масштабируется под заполнение `1080x1920`, обрезается по центру и размывается
* слой переднего плана: исходный горизонтальный клип, увеличивается примерно на `20%`, слегка обрезается и центрируется поверх фона

Это поведение реализовано в `EditorStandard`.

## Сборка под Windows

Поддержка PyInstaller уже настроена.

Установка зависимости для сборки:

```bash
pip install pyinstaller
```

Сборка GUI-приложения:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

Результат:

* исполняемый файл будет создан в `dist\FinalProjectVideoCutter\`

Важно:

* FFmpeg всё ещё должен быть доступен на целевой машине, если вы не упаковываете его отдельно.
* Веса моделей Whisper не включаются в сборку автоматически.

## Передача конечным пользователям

Есть 2 практических варианта поставки.

### Вариант 1: переносимая CPU-first сборка

Подходит, если вы хотите, чтобы приложение запускалось почти на любом Windows-ПК.

Что передавать:

* всю папку `dist\FinalProjectVideoCutter\`
* при желании короткий `README_runtime.txt` с инструкцией по запуску

Что пользователю ещё потребуется:

* FFmpeg в `PATH`, либо отдельный FFmpeg рядом с `.exe`, подключённый в стартовой логике

Поведение:

* если GPU недоступна, приложение автоматически работает на CPU
* если есть NVIDIA GPU, но отсутствует CUDA PyTorch, приложение предупредит и продолжит работу на CPU

### Вариант 2: Windows-сборка с поддержкой GPU

Подходит, если у получателя есть NVIDIA GPU и нужна аппаратная акселерация.

Что передавать:

* всю папку `dist\FinalProjectVideoCutter\`
* FFmpeg с поддержкой NVENC, либо инструкцию по его установке
* точное окружение PyTorch с поддержкой CUDA или инструкции по установке

Что обязательно должно быть у пользователя:

* установленный драйвер NVIDIA
* сборка PyTorch с поддержкой CUDA
* сборка FFmpeg с `h264_nvenc`

Поведение:

* если все требования выполнены, приложение автоматически использует GPU
* иначе приложение откатится на CPU и покажет предупреждение

## Рекомендуемые файлы для пользователя
